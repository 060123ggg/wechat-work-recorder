微信记工助手 0.2.1 · 双击启动版（Windows 10/11 64位）

1. 将下载的 ZIP 全部解压到一个新文件夹。不要在 ZIP 预览窗口中运行。
2. 双击「启动微信记工助手.bat」。会出现黑色窗口，稍后打开助手。
3. 不需要另外安装 Python 或 Tesseract。不要只拷贝单独的 exe；
   _internal、tesseract 等文件夹需要保留在程序旁。
4. 关闭旧程序后再使用新版本。升级请选择新文件夹，不覆盖旧测试目录。

现有名册、昵称、价格和复制历史继续保存在当前 Windows 用户的
%APPDATA%\WechatWorkRecorder 中。这个目录不在程序 ZIP 内。
测试前可复制备份此目录；两台电脑各有自己的本机资料，不会自动同步。
本版不更改本机资料结构，只在已有 imports.sqlite3 审核表中追加
忽略/合并说明，不删除或更改以前的工资历史。

待核对区点击一项会跳到原文并打开审核；取消可暂不处理。
疑似重复项可选择独立计薪、忽略、或合并（保留原工资，不再加算）。
忽略只适用于当前原文批次；改变原文/群或重启重新导入，需要再次审核。

只在模拟账本或工资表副本中测试 WPS 三段复制。
先把 F 列设为文本，保留 J 公式及 K 合并合计。
软件不写真实工资表，也不能验证当前 WPS 选区是否正确。

程序未做代码签名，请确认附件来自官方仓库的本轮成功 Actions 构建。
遇到启动错误请保留黑色窗口提示，并核对界面标题版本为0.2.1。
